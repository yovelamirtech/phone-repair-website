# פיקסלאב — אתר מעבדת סלולר

אתר סטטי למעבדת תיקון טלפונים בכרמיאל. בנוי ב־React, TypeScript ו־Tailwind, ונפרס אוטומטית ל־GitHub Pages בכל דחיפה לענף `main`.

**כתובת האתר:** https://yovelamirtech.github.io/phone-repair-website/

> כל התוכן באתר כרגע **לדוגמה בלבד**: שם העסק, כתובת, טלפון, מחירים, מבצעים, ביקורות ותמונות. בראש כל דף מוצג פס "אתר בהדגמה", וכל הדפים חסומים לגוגל (`noindex`) עד שמכבים את מצב הדמו.

---

## הרצה מקומית

צריך Node.js 22 ומעלה.

```bash
npm install        # התקנה
npm run dev        # שרת פיתוח: http://localhost:5173/phone-repair-website/
npm run build      # בנייה לתיקייה dist
npm run preview    # הצגת הבנייה מקומית
npm run check      # בדיקת טיפוסים + לינט + בדיקות (אותו דבר שרץ לפני כל פריסה)
```

## פריסה

כל `git push` לענף `main` מריץ את `.github/workflows/deploy.yml`: בדיקת טיפוסים, לינט, בדיקות, בנייה ופריסה ל־GitHub Pages. אם אחד השלבים נכשל, הפריסה נעצרת והאתר החי לא משתנה.

### פרטי העסק

ב־`src/data/business.ts`:

- `phone`: הטלפון כפי שהוא מוצג, למשל `04-123-4567`.
- `phoneE164`: אותו מספר בפורמט בינלאומי לקישור חיוג, למשל `+97241234567`.
- `whatsapp`: מספר הוואטסאפ בפורמט בינלאומי, **ספרות בלבד**, בלי `+` ובלי מקפים, למשל `972501234567`. ממנו נבנים כל כפתורי הוואטסאפ, כולל ההודעה המלאה אחרי הזמנה.
- `hours`: שעות הפתיחה לפי יום (0 = ראשון ... 6 = שבת). אפשר כמה טווחים ביום, למשל הפסקת צהריים: `[{ open: '09:00', close: '13:00' }, { open: '16:00', close: '19:00' }]`. מערך ריק = סגור. מהשעות האלה מחושבים "פתוח עכשיו" והתורים הפנויים בהזמנה, תמיד לפי שעון ישראל.
- `geo`: קואורדינטות למפה ולכפתורי הניווט (ווייז וגוגל מפות).

שם העסק מופיע גם בטקסטים: בכל מקום שכתוב `{{businessName}}` הוא נלקח אוטומטית מ־`business.ts`. בנוסף צריך לעדכן את `seo.siteName`, `seo.defaultTitle` ו־`seo.defaultDescription` ב־`src/i18n/locales/he/common.json`.

### מחירים

המחיר לכל דגם ותיקון מחושב בקוד: **מחיר בסיס × מקדם רמת המחיר**, ומעוגל למחיר שמסתיים ב־9 או ב־0.

- מחירי הבסיס: `basePrice` ב־`src/data/repairs.ts`. למסך ולסוללה יש שני מחירים: `original` ו־`compatible`.
- המקדמים: `tierMultipliers` באותו קובץ (`basic` 0.6, `mid` 0.85, `flagship` 1.3, `premium` 1.9).
- רמת המחיר של כל דגם: הפרמטר השני בכל שורה ב־`src/data/devices.ts`, למשל `m('iPhone 16', 'mid', 2024)`.
- **מחיר ידני לדגם מסוים** גובר על החישוב:
  ```ts
  m('iPhone SE (2022)', 'basic', 2022, { priceOverrides: { 'screen:original': 290, charging: 199 } })
  ```
- **תיקון שלא רלוונטי לדגם** (למשל גב פלסטיק): `{ excludeRepairs: ['backGlass'] }`.
- המחירון וההערכה בהזמנה משתמשים באותה פונקציה בדיוק (`src/lib/pricing.ts`), ויש בדיקות שמוודאות שהם תמיד זהים.

### דגמים חדשים

מוסיפים שורה בסדרה המתאימה ב־`src/data/devices.ts`. מזהה הדגם (לקישורים) נוצר אוטומטית מהשם. אם יש מילת חיפוש בעברית שאנשים משתמשים בה ליצרן, מוסיפים אותה ל־`searchAliases` של היצרן.

### מבצעים

ב־`src/data/promos.ts`: כותרת, שורת משנה, טקסט וקישור לכפתור, שם תמונה וגוון רקע (`blue`, `green`, `amber`, `violet`). קישור להזמנה עם תיקון מסומן מראש: `/order?repair=battery`. קישור להזמנה עם דגם ותיקון: `/order?model=iphone-15-pro&repair=screen&quality=compatible`.

### תמונות

התמונות נשמרות ב־`public/images/photos` בפורמט WebP, בשלושה רוחבים (480, 960, 1600).

**להחלפת תמונה בתמונה משלכם:**
1. ממירים את התמונה ל־WebP בשלושת הרוחבים, ושומרים כ־`<שם>-480.webp`, `<שם>-960.webp`, `<שם>-1600.webp` בתיקייה `public/images/photos`.
2. מוסיפים או מעדכנים את השם ב־`src/data/images.generated.json` (רוחב, גובה ויחס).
3. משתמשים בשם בקובץ הנתונים, למשל `image: 'my-photo'` ב־`promos.ts`.

**או אוטומטית:** מוסיפים שורה ל־`scripts/images.sources.json` עם קישור לתמונה, ומריצים `npm run images:fetch`. הסקריפט מוריד, ממיר, מעדכן את `images.generated.json` וכותב את `public/images/CREDITS.md`. אם תמונה חסרה, האתר מציג רקע בהיר נקי במקומה ולא תמונה שבורה.

**הלוגו:** `public/images/logo.svg` ואייקוני האפליקציה נוצרים מהסקריפט `npm run brand:generate`. כשיהיה לוגו אמיתי, פשוט מחליפים את `logo.svg` ואת הקבצים ב־`public/icons`, `public/favicon.svg` ו־`public/og-image.png` (תמונת השיתוף, 1200×630).

## הפעלת שפה נוספת

האתר מוכן לאנגלית ולרוסית. הקבצים `src/i18n/locales/en` ו־`ru` קיימים, עם אותם מפתחות כמו בעברית וערכים ריקים. כל ערך ריק מוצג בעברית.

1. ממלאים את התרגומים ב־`src/i18n/locales/en/*.json`.
2. בקבצי הנתונים, שדות טקסט הם אובייקט לפי שפה: מוסיפים `en`, למשל `name: { he: 'החלפת מסך', en: 'Screen replacement' }`.
3. ב־`src/config/site.ts` מוסיפים את השפה: `enabledLanguages: ['he', 'en']`.

מרגע שיש יותר משפה אחת, בורר השפות מופיע בכותרת ובתפריט. בהחלפת שפה הכיווניות מתהפכת אוטומטית (`dir="ltr"`), הגופן מתחלף ל־Inter, ותאריכים ומחירים מעוצבים לפי השפה. הבחירה נשמרת בדפדפן.

כשמוסיפים טקסט חדש לעברית, מריצים `npm run locales:sync` כדי שהמפתח יתווסף גם לאנגלית ולרוסית. יש בדיקה שנכשלת אם הקבצים לא מסונכרנים.

ב־`src/config/site.ts`:

```ts
demoMode: false,
```

זה מסיר את פס "אתר בהדגמה", את הרמז להזמנות לדוגמה בדף הסטטוס ואת ההערות על התוכן לדוגמה, ומסיר את חסימת גוגל (`noindex`). לפני כן חשוב להחליף את כל התוכן המומצא (רשימה בסוף).

## חיבור טופס אמיתי

כל השליחות עוברות דרך קובץ אחד: `src/services/orders.ts`. כרגע הן שומרות בדפדפן של המבקר בלבד, אחרי השהייה של שנייה. כדי לחבר שירות אמיתי, מחליפים **רק** את גוף הפונקציות:

- `submitOrder(input)` — שליחת הזמנה. מחזירה `{ orderNumber }`.
- `getOrderStatus(orderNumber, phoneLast4)` — בדיקת סטטוס. מחזירה את הסטטוס, או `null` אם לא נמצא (או אם הספרות לא מתאימות).
- `submitContactMessage(input)` — טופס צור קשר.

דוגמה עם שירות טפסים כמו Formspree:

```ts
export async function submitContactMessage(input: ContactInput): Promise<void> {
  const res = await fetch('https://formspree.io/f/<FORM_ID>', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', Accept: 'application/json' },
    body: JSON.stringify(input),
  });
  if (!res.ok) throw new Error('send failed');
}
```

אפשרויות נוספות: Google Apps Script שכותב לגיליון גוגל, Make/Zapier, או שרת משלכם. שום רכיב אחר לא צריך להשתנות. כפתור "שלח בוואטסאפ" כבר עובד באמת, ברגע שמכניסים מספר אמיתי ב־`business.ts`.

## מעבר לדומיין משלכם

1. ב־`src/config/site.ts`: `basePath: '/'` ו־`siteOrigin: 'https://www.your-domain.co.il'`.
2. מוסיפים קובץ `public/CNAME` עם שם הדומיין, ומגדירים את הדומיין בהגדרות ה־Pages במאגר.

כל הנתיבים לתמונות, לקישורים, למפת האתר ולתגיות השיתוף נגזרים משתי השורות האלה.

## החלטות שהתקבלו במהלך הבנייה

החלטות שהתוכנית לא הגדירה, או שבהן נדרשה סטייה קטנה ממנה:

1. **חשבון GitHub:** המאגר נמצא ב־`yovelamirtech/phone-repair-website` (החשבון `yovleztech` לא קיים, ואושר להשתמש ב־`yovelamirtech`). המאגר ציבורי, כדי שאפשר יהיה להשתמש ב־Pages בחינם.
2. **צבעי טקסט:** המבטא `#2F6BFF` נותן ניגודיות של 4.498:1 מול לבן, קצת מתחת ל־4.5. לכן כפתורים וקישורים משתמשים בגוון כהה מעט יותר, `#2563EB`, והמבטא המקורי נשאר לאייקונים ולמסגרות מוקד. באותו אופן נוספו גרסאות כהות לטקסט של הצלחה (`#157A41`), אזהרה (`#9A5B00`) ושגיאה (`#B3261E`). הצבעים המקוריים משמשים לנקודות ולאייקונים.
3. **וואטסאפ:** כפתורי וואטסאפ בגוון הטורקיז הכהה של וואטסאפ (`#0F7A6E`) ולא בירוק הבהיר, כי טקסט לבן על הירוק הבהיר לא עומד בניגודיות. סמל הוואטסאפ הוא קובץ נפרד (`whatsapp-white.svg`, מ־Simple Icons).
4. **שישה שלבים בהזמנה:** התוכנית מתארת 3 שלבים ומסך אישור, אבל מבקשת "שישה שלבים קצרים". חילקתי ל: יצרן, דגם, תקלה, מועד, פרטים, סיכום, ואחריהם מסך האישור. בחירת יצרן ודגם מעבירה לשלב הבא אוטומטית.
5. **שמירת טיוטת ההזמנה** ב־sessionStorage (נמחקת כשסוגרים את הלשונית), וההזמנות שנשלחו ב־localStorage.
6. **סטטוס הזמנה בדמו:** הזמנה שנוצרה באתר מתקדמת שלב אחד כל 3 דקות, כדי שאפשר יהיה לראות התקדמות בזמן סביר.
7. **תורים תפוסים:** כ־30% מהתורים מסומנים "תפוס" לפי חישוב קבוע מהתאריך והשעה, כך שהם לא משתנים ברענון.
8. **רמות מחיר:** "פרימיום" שמור למתקפלים, כמו בתוכנית. דגמי Pro ו־Ultra הם "פלאגשיפ", דגמים רגילים מהשנים האחרונות "בינוני", ודגמים ישנים או זולים "בסיסי". בדגמים זולים עם גב פלסטיק לא מוצעת החלפת זכוכית אחורית.
9. **רשימת הדגמים** עודכנה ל־26.11.2026 ונבדקה בחיפוש ברשת לאפל, סמסונג וגוגל (כולל iPhone 18 Pro, iPhone 17e, Galaxy S26, Z Fold8/Flip8 ו־Pixel 11). אייפון מתקפל לא נכלל, כי מועד היציאה שלו עוד לא אושר.
10. **ניתוב:** `createBrowserRouter` עם כתובות נקיות. דף הבית נטען עם המעטפת, וכל שאר הדפים נטענים כקובץ נפרד.
11. **מעטפת סטטית ו־CSS מוטבע:** כדי שמשהו יופיע מהר גם בחיבור איטי, ה־HTML כולל את פס ההדגמה ואת הלוגו, והעיצוב מוטבע בו. התמונה הראשונה של הבאנר נטענת מראש, רק בדף הבית.
12. **הבאנר:** כותרות השקופיות הן פסקה ולא כותרת, כדי שהכותרת הראשית (H1) תהיה הראשונה בדף. כשהמשתמש ביקש פחות תנועה, הבאנר לא מתחלף לבד, אבל אפשר להפעיל אותו בכפתור.
13. **סרגל לפני ואחרי** בנוי על פקד טווח (`range`) רגיל של הדפדפן, שעובד במגע, בעכבר ובמקלדת. "לפני" תמיד בצד שמאל, גם בעברית.
14. **מפה:** OpenStreetMap במקום גוגל מפות, כי הוא לא דורש מפתח ולא מוסיף עוגיות מעקב. המפה נטענת רק כשגוללים אליה.
15. **אימות טלפון:** נייד ישראלי שמתחיל ב־05, 10 ספרות, עם מקפים או בלי (`050-1234567`, `050-123-4567`, `0501234567`).
16. **מספרים בטקסט עברי** (טלפון, מספר הזמנה, שעות) עטופים בכיווניות משמאל לימין, ובהודעות שגיאה משתמשים בתווי בידוד של Unicode.
17. **תמונות:** 17 תמונות מ־Unsplash, בלי פנים של אנשים ובלי תמונות שיווק של יצרנים. תמונה אחת עם לוגו אפל בולט הוחלפה. בגלריה, התמונות של "לפני" ו"אחרי" הן של מכשירים שונים, ולכן הן לדוגמה בלבד.
18. **דף 404 ב־GitHub Pages** מוחזר עם קוד 404 גם כשהדף עצמו נטען כראוי. זו מגבלה של Pages. בעתיד, יצירה מראש של קובץ HTML לכל דף תפתור את זה (כמו שהתוכנית מציינת).
